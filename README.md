# ML–LIS 论文最终结果复现包

本文件夹提供一套最终数据和一条完整分析流程。运行 `run.py`，即可从随附记录重新生成正文、图 1–7、表 1–4、附录 A 和附录 B 的最终结果，以及附录 C 的检索表达式。所有计算规则均已整合进代码，无须先运行旧版本或追加修补程序。

**复现起点是归档并已核验的文献元数据。** DOI 补充信息、参考文献年份和期刊分类采用冻结的最终数据；程序自行完成标识规范化、文献合并、筛选、引用去重、匹配、任务分配、汇总、相关检验与绘图。不重新联网抓取 PwC、WoS、arXiv 或 Semantic Scholar，也不读取本文件夹外的旧代码、手稿或结果表。

## 运行

建议使用 **Python 3.12**。先在本文件夹中打开终端，再执行：

```sh
python -m pip install -r requirements.txt
python run.py
```

安装依赖后，分析可完全离线运行，不需要 R、Word、API 密钥或手工调整路径。首次绘图可能需要建立字体缓存。

默认结果写入本文件夹中的 `results/`。如需改变输出位置：

```sh
python run.py --output "其他输出文件夹"
```

For collaborators: install the pinned requirements with Python 3.12 and run `python run.py`. All data dependencies are bundled. The analysis runs offline and writes its outputs to `results/`.

## 核心计算口径

1. **标识与文献合并。** DOI 去除网址前缀、统一大小写并进行格式检查；arXiv 去除版本号，按历史编号规则标准化。PwC 共享 arXiv 标识，或具有唯一对应关系的 DOI 时合并；标签取不同原始标签的并集。出版年份取记录中的众数，并列时取最早年份。指向多个不同 PwC 文献的 DOI 不参与 DOI 匹配，仍可通过无歧义 arXiv 标识匹配。
2. **引用池。** 保留 2017–2022 年、具有有效引用论文 DOI 且参考文献年龄非负的记录。缺失年份和负年龄记录不进入分析池。同一引用论文内，按被引 DOI、其次 arXiv 标识识别重复参考文献；二者均缺失时保留原始行身份。DOI 与 arXiv 匹配相同文献时合并，同一 LIS–PwC 引用关系只计一次。两种标识发生冲突时不强行选择其一。
3. **图 2、图 3 与重叠。** 年度分母是该年分析池中的不同 LIS 论文数。主题检索结果也限制到同一论文池。交集分别除以两个集合各自大小，不将这两个比例当作匹配准确率或召回率。
4. **引用年龄。** 先对每篇引用论文内部的参考文献年龄取平均，再跨论文求均值、中位数和标准差，标准差使用 `ddof=1`。年度表同样先在论文内部平均。
5. **图 5。** ML 组由 PwC 匹配确定。其他学科只使用未匹配参考文献的归档 `fields_of_study` 标签；多标签参考文献完整计入各标签组，无标签者不进入其他学科组。每个学科组仍先在引用论文内部求平均。
6. **图 6。** 每个点是一篇 LIS 论文：横轴为匹配 ML 参考文献数除以全部合格参考文献数，纵轴为其余未匹配参考文献的平均年龄。没有合格未匹配参考文献的三篇论文不进入相关检验，最终 `n=3,248`。报告双侧 Pearson 检验及 Fisher 变换的 95% 置信区间；红线为 LOWESS，`frac=2/3, it=3`。
7. **分数计数。** 每个不同原始任务标签贡献权重 1，而不是每篇论文总权重为 1。已经处于目标层级的标签保留权重 1；其他标签沿匹配到的归档层级路径平均分配，抵达相同类别的分数相加。父、子标签都存在时仍为两个不同原始赋值；相同原始标签在合并文献内部只保留一次。LIS 一侧的赋值按不同引用关系贡献，PwC 基准一侧按合并后的不同文献贡献。两个层级独立计算，双方使用相同映射。
8. **目录覆盖与分母。** 图 4 只统计能匹配目录的不同类别。未匹配标签仍计入表 4 总赋值权重的分母。表 4 使用 LIS 2017–2022 与 PwC 2010–2022；分母包括残余类别和未匹配标签，展示十个最高的可解释目录类别。
9. **图 7。** 双方都限制在 2017–2022，保留两侧计数均为正的共同标签，去掉 Methodology 与 Miscellaneous，再在各自纳入标签内归一化。共有 156 个点：14 个一级目录类别和 142 个未匹配标签。纵轴为 `log2(LIS share / PwC share)`，气泡大小由 LIS 份额决定；标签引线不改变点的位置。
10. **增长相关性。** 对每个任务计算 `(2022 count - 2017 count) / 2017 count`。只纳入能匹配目录、且双方两个端点均为正的任务，一级再排除两个残余类别。相关性是在不同任务之间计算，而不是对六个年度点计算。Spearman 对并列值采用平均秩和双侧 t 近似。24 项检验统一进行 Holm 调整。分数权重在汇总边界使用一致的 CSV 数值读写精度，不先把权重或增长率四舍五入，以保持并列秩的可复现性。
11. **期刊敏感性分析。** M0 保留完整分析池；M1 排除 IPM；M2 排除预先标记的 CS/IR 边界期刊；M3 再排除 MIS/IS 边界期刊；M4 仅保留核心 LIS 分组；M5 排除 M2 期刊以及任一 ASJC 代码以 `17` 开头的期刊。全部次级代码均直接参与 M5 判断。各模型的分子、分母来自同一份分析池。
